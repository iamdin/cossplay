How it works

Cossplay only overrides the variables you change. Everything else keeps following the site.

  1. Open a coss ui site

    The extension reads the page's theme variables from :root, .dark and @theme.

  2. Edit in the side panel

    Pick a preset or tweak tokens. The page updates instantly in light or dark.

  3. Export the code

    Copy or download CSS shaped like coss ui's globals.css, ready to paste into your project.

Export to your stack

Import from a tweakcn or registry URL, pasted CSS or JSON, then take it anywhere.
